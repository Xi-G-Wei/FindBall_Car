# FindBall_Car

一台自己找乒乓球、开过去把它收进框里的四轮小车。

摄像头在 **K230** 上做 YOLOv8 推理，把球在画面里的坐标通过串口发给 **STM32**，由 STM32 决定车往哪走。

> 机构是"拖框"：框装在车**后面**，靠车往前开、框扫过球来收球。
> 所以「球已对正」时车必须**继续前进**，而不是停车 —— 不停下来才扫得到。

## 仓库结构

```
FindBall_Car/
├── camera/        K230 摄像头端 —— YOLO 检测 + 串口上报坐标
└── controller/    STM32 主控端 —— 收坐标、控制底盘
```

## 硬件

| | 型号 | 说明 |
|---|---|---|
| 主控 | STM32F103C8T6 | 四轮底盘板，DRV8701 驱动，板载 CH32 调试器（烧录接口选 `cmsis-dap`） |
| 摄像头 | K230D CanMV 庐山派 Lite | 128M 版，gc2093 传感器，YOLOv8n 320×320 |
| 电机 | 4× 直流减速电机 | 需要独立 12V 供电 |

## 串口协议（115200 8N1）

物理层走 **USART3**。STM32 侧 **PB10 = TX（输出）/ PB11 = RX（输入）**，所以接线是**交叉**的：

```
K230 IO3 (TX) ──→ STM32 PB11 (RX)
K230 IO4 (RX) ──→ STM32 PB10 (TX)
GND ──────────── GND            ← 必须共地，否则收到的全是乱码
```

| 报文 | 含义 |
|---|---|
| `"412,238\n"` | 球框中心坐标（K230 的显示坐标，800×480） |
| `"Mf\n"` `"Mb\n"` `"Ml\n"` `"Mr\n"` `"Ms\n"` | 遥控：前进 / 后退 / 左转 / 右转 / 停（**仅手动模式生效**） |
| `"MM\n"` / `"MA\n"` | 切换 手动 / 自动 模式 |
| （什么都不发） | 画面里没有球 |

**自动追球时，K230 只说"球在哪"，不说"该往哪走"。** 丢球之后是冲、是停、是转圈找，全部由 STM32 按"多久没收到坐标"自己判断 —— 丢失判断只放在一个地方，两边各有一套时间必然打架。

手动模式下另有 `MANUAL_LOST_MS = 500` 兜底：500ms 没收到新指令自动停车。

## 控制逻辑（`controller/User/main.c`）

只有一个判断依据：距离上次收到坐标过了多久（`lost_ms`）。

```
       0 ──── 300ms ──────────── 2000ms ────────────▶
       │        │                   │
    正常跟踪   刚丢几帧            球真没了
               什么都不做          → 继续直行冲过去
               （当抖动容忍）
                                  超过 2000ms → 原地右转找下一颗
```

- **正常跟踪** —— 球偏右走右弧线，偏左走左弧线，对正了直行
- **抖动容忍** —— K230 的检测偶尔会闪掉一两帧，这段时间不动方向盘，免得车跟着抖
- **直行冲击** —— 球从画面下边沿消失后继续直行一段，把球扫进框
- **原地搜索** —— 冲完还是没有球，原地右转

### 参数含义与调参影响

| 参数 | 默认 | 说明 |
|---|---|---|
| `AIM_X` | 400 | 车正前方在画面里的 x。**不是画面中心**，摄像头装歪一点两者就不等，必须实测 |
| `DEADZONE` | 30 | 允许的横向误差，在这个范围内算对正 → 直行。调大更稳，调小更容易左右摆 |
| `TRACK_SPEED` | 900 | 前进速度。⚠️ 必须 > `TRACK_STEER`，否则转弯时内侧轮会倒转 |
| `TRACK_STEER` | 400 | 转向量。转弯时内轮速度 = SPEED − STEER，要明显大于电机死区 |
| `SEARCH_STEER` | 400 | 找不到球时的原地右转速度 |
| `LOST_DEAD_MS` | 300 | 抖动容忍时长 |
| `LOST_FORWARD_MS` | 2000 | ⚠️ 球消失后直行多久。这是**距离**不是时间：`LOST_FORWARD_MS × TRACK_SPEED` 就是冲多远，带负载和不带负载差很多，必须实测 |

## 编译（controller/）

用 **EIDE**（VS Code 插件）+ Keil **AC5** 工具链。

1. 用 EIDE 打开 `controller/` 目录
2. 装芯片支持包 **Keil.STM32F1xx_DFP 2.3.0**（EIDE 里能直接下；仓库里没带，因为光 SVD 寄存器文件就有好几 M）
3. 编译，用 **cmsis-dap** 接口烧录

> 没带进仓库的目录（`.pack/`、`.cmsis/`、`build/`）都是本地装/生成的，不影响源码阅读。
